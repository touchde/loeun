# loeun-core

The download engine behind [Loeun](https://github.com/touchde/loeun): segmented, resumable, multi-connection downloads.

This crate is under active development and its API is not stable yet. See the repository's [engine design](https://github.com/touchde/loeun/blob/main/docs/ENGINE_DESIGN.md) for how it works.
